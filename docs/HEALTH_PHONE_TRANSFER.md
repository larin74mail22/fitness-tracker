# Передача выгрузок Health Connect с телефона на компьютер

## Сравнение вариантов

| Вариант | Что нужно установить | Автоматически | Компьютер выключен | Безопасность сети | Итог |
|---|---|---|---|---|---|
| **Syncthing** (папка синхронизации) | Syncthing-Fork на телефон, Syncthing на компьютер | да, после разовой настройки | файлы ждут на телефоне и уйдут при включении | шифрование, только сопряжённые устройства, без открытых портов в интернет | **основной** |
| USB + adb (`scripts\pull_from_phone_adb.ps1`) | Android SDK Platform-Tools (adb) | нет, по кабелю | — | только кабель | **резервный** |
| «Поделиться» → ChatGPT (`import_health_export`) | ничего | нет | работает без компьютера, импорт при работающем туннеле | файл идёт через ChatGPT | как раньше |
| Свой HTTP-сервер или Wi-Fi-сервис на компьютере | — | — | — | открытый порт в локальной сети, нужна аутентификация | не делали |

Приложение FITNESS Health Export по-прежнему без доступа к интернету: с версии 0.3 оно само кладёт копию каждого
нового файла в выбранную **папку синхронизации**, а по сети её переносит Syncthing. Файл пишется под временным
именем `.<имя>.tmp` и переименовывается, когда записан целиком: ни Syncthing, ни импортёр не возьмут недописанный файл.

## Основной путь: Syncthing (разовая настройка)

Настройка описана в общем виде; названия пунктов меню зависят от производителя телефона.

**Компьютер**
1. Скачать Syncthing для Windows с https://syncthing.net/downloads/ и запустить (веб-интерфейс http://127.0.0.1:8384/).
   Брандмауэр Windows спросит разрешение — разрешить для **частной** сети.
2. Действия → Показать ID — понадобится на телефоне.

**Телефон (Android)**
3. Установить **Syncthing-Fork** из F-Droid (пакет `com.github.catfriend1.syncthingfork`). Разрешить уведомления
   и работу в фоне; в настройках батареи телефона снять ограничения фоновой работы для Syncthing-Fork.
4. Обновить FITNESS Health Export до 0.4.0 (см. ниже). В приложении: «Папка синхронизации…» → создать папку,
   например `Documents/FITNESS-Health`, → «Использовать эту папку» → «Разрешить».
5. В Syncthing-Fork: Устройства → «+» → ввести ID компьютера. Папки → «+» → путь `Documents/FITNESS-Health`,
   тип папки **«Только отправка»**, отметить компьютер.

**Компьютер**
6. В веб-интерфейсе Syncthing принять устройство и папку; путь папки:
   `<папка проекта>\data\health_syncthing` (не `health_inbox`!), тип **«Только приём»**.
   Импорт эту папку только читает и копирует новые файлы в `data\health_inbox`, поэтому у Syncthing не бывает
   «локальных изменений» и кнопки «Отменить локальные изменения». Если папка раньше была настроена на
   `health_inbox` — перенастройка без повторного сопряжения описана в `docs/HEALTH_SYNCTHING.md`.
   По желанию: «Ignore Delete» (Действия → Дополнительно → Папки): чистка папки на телефоне не удалит файлы на
   компьютере. На телефоне файлы остаются в папке синхронизации (каждый 0,3–10 МБ); старые можно удалять вручную.
7. Запустить `health_import_inbox.bat --watch` (или установить автозапуск, `docs/HEALTH_AUTO_IMPORT.md`).

**Каждый день:** открыть FITNESS Health Export → «Экспортировать данные». Дальше всё само: Syncthing переносит
файл, наблюдение импортирует его, ChatGPT и панель видят данные. Если компьютер выключен, файл уйдёт при
следующем включении (номер файла и нахлёст периода защищают от потери данных).

С версии 0.4.0 можно не нажимать и кнопку: раздел «Фоновый экспорт» (ниже) создаёт файл по расписанию.

## Фоновый экспорт (0.4.0, по желанию)

Выключен по умолчанию. Включается в приложении кнопкой «Включить фоновый экспорт»: Health Connect попросит
отдельное разрешение **«Доступ к данным в фоне»** (`READ_HEALTH_DATA_IN_BACKGROUND`); без него фоновый экспорт не
включится. Других новых разрешений нет (интернета у приложения по-прежнему нет).

- Интервал: раз в 6 ч, 12 ч или сутки — «не чаще, чем»; Android сам выбирает момент и может откладывать запуск
  (сон устройства, экономия батареи, заряд ниже низкого). Точного времени нет.
- Период всегда «С последнего экспорта» с нахлёстом 3 дня; файл кладётся в папку синхронизации, если она выбрана.
- Временная ошибка (Health Connect занят, лимит запросов) — до трёх попыток с растущей паузой от 15 минут.
- Ручной и фоновый экспорт не идут одновременно; номер файла не повторяется.
- Отозвали разрешение — запуск записывает «нет разрешения» и не повторяется до следующего периода; расписание
  остаётся, после повторной выдачи продолжит само.
- Результат последнего фонового запуска и время следующего виден в приложении.

Разовая настройка на телефоне (названия пунктов зависят от производителя): «Настройки приложения (батарея, работа в фоне)…» → Батарея → разрешить фоновую
активность, иначе система может надолго откладывать запуски. Если Health Connect не поддерживает чтение в фоне
(старая версия), приложение скажет об этом; ручной экспорт работает как раньше.

## Резервный путь: USB-кабель и adb

1. Телефон: Настройки → О телефоне → 7 раз «Версия ПО»; Параметры разработчика → «Отладка по USB».
2. Подключить кабель, подтвердить запрос на телефоне.
3. `powershell -ExecutionPolicy Bypass -File scripts\pull_from_phone_adb.ps1 -Import`

Скрипт читает файлы приложения (`run-as`, работает только с отладочной сборкой app-debug.apk), сверяет SHA-256
с телефоном, кладёт новые файлы в `data\health_inbox` и с `-Import` сразу импортирует. Уже забранные файлы не
копирует. Приложение хранит 10 последних файлов.

## Обновление APK до 0.4.0

Приложение FITNESS Health Export — отдельный Android-проект, в этот репозиторий не входит. APK собирается из него
(отладочная сборка `app-debug.apk`, подпись тем же ключом, что и прежние версии). Ставится **поверх**, удалять старую версию нельзя (удаление стирает `phone_id`
и номер файла):

- по кабелю: `adb install -r <путь к app-debug.apk>`;
- без кабеля: скопировать APK на телефон и открыть в «Файлах».

После обновления разрешения Health Connect, `phone_id`, номер файла и режим сохраняются.
**Сначала обновите трекер на компьютере** (эта версия кода): старый импортёр не знает полей `period_start` и
`period_end` и отклонит новые файлы.
